Backup and your data

Save, restore, or delete everything

Everything Tirekick keeps lives only in this browser. A backup file holds your saved listings and searches, each search's filter and price, what you've hidden, what you've seen, spending and these settings, but never your API keys. Restoring adds to what's here and takes the backup's settings.

Delete everything removes what Tirekick keeps in this browser: your API keys, saved listings and searches, what you've hidden and seen, spending, and these settings. Save a backup first if you might want it back. Uninstalling the extension deletes it all too.

Scores, prices, margins and warnings are estimates to help you decide, not advice or a guarantee: a model can be wrong and sold prices are approximate, so check the listing and the seller yourself.
